# North Business web
Sitio estático, sin build. `index.html` = portada, `break-even/` = calculadora (calc.js = lógica, app.js = interfaz).
Prueba de la lógica: `node break-even/test.js`.

## Publicación
GitHub + Cloudflare Pages (gratis). Cloudflare Pages: sin comando de build, carpeta de salida `/` (raíz del repo).
Cada cambio que se sube a `main` se publica solo.
